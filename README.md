# MegaBull (MBULL)

**Website: https://mbull-two.vercel.app/**

MegaBull is a BNB Smart Chain token for Binance .ai Agent ID holders.

- Contract: 0x544aC5e9F1e853800116eFFf1CB9f8fb0B6E8f10 (chain 56)
- Total supply: 20,000,000 MBULL — 16,000,000 mintable, 4,000,000 LP reserve
- Mint: 1,000 MBULL per mint, max 10 mints per wallet, 0.0005 BNB mint fee per mint, gas separate. The creator mints free.
- Tax: 2% buy / 2% sell, only on PancakeSwap pair trades, only after launch. The creator's tax share is used for token buybacks, manual, not automatic.
- Transfers are locked until launch.

See `skill.md` for the agent minting skill, and `MegaBull.sol` for the contract source.
